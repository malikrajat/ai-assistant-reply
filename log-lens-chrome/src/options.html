Permissions explained

Log Lens asks for the smallest set Chrome allows.

  • storage — persist settings, logs, and the auto-send outbox locally.
  • alarms — scheduled auto-send and retention sweeps.
  • notifications — desktop alert when a new error is captured.
  • downloads — save exported logs and screenshots.
  • clipboardWrite — copy logs and reports after a user action.
  • activeTab — capture the visible page only after you act.
  • scripting / sidePanel / contextMenus — page bridges, the log panel, and shortcuts.
  • Optional tabs / webRequest / host permissions — requested only when you enable network or page capture, or configure an auto-send endpoint.

No analytics, no remote code, no account, and no default network destination. See the README for the full privacy model.

Changes are saved to chrome.storage.local.
